Welcome to sollertia-video-tracking API documentation page
==========================================================

Provides assets for designing and deploying DeepLabCut video tracking pipelines within the Sollertia platform.

This library is part of the `Sollertia <https://github.com/Sun-Lab-NBB/sollertia>`_ AI-assisted scientific data
acquisition and processing platform, built on the `Ataraxis <https://github.com/Sun-Lab-NBB/ataraxis>`_ framework and
developed in the `Sun (NeuroAI) lab <https://neuroai.github.io/sunlab/>`_ at Cornell University. It wraps
`DeepLabCut <https://github.com/DeepLabCut/DeepLabCut>`_ 3.x to provide hardware-optimized model training, multi-device
video inference, and parallel frame-extraction pipelines for the platform's pose-estimation workflows.

This website only contains the API documentation for the classes and methods offered by this library. See the project
GitHub repository for installation instructions and library usage examples:
`sollertia-video-tracking GitHub repository <https://github.com/Sun-Lab-NBB/sollertia-video-tracking>`_.
